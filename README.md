# 矩阵草稿台

面向线性代数初学者的本地矩阵演算草稿工具。使用 Vue 3、TypeScript 和 Vite 构建。

## 本地运行

```sh
npm install
npm run dev
```

终端会显示本地访问地址。生产构建使用：

```sh
npm run build
```

## GitHub Pages

仓库为 [i11umination/matrix-scratchpad](https://github.com/i11umination/matrix-scratchpad)，网页名称为“矩阵草稿台”。推送到 `main` 后，GitHub Actions 会安装依赖、构建项目并发布 `dist`。网站地址：[矩阵草稿台](https://i11umination.github.io/matrix-scratchpad/)。

## 第一版功能

- 在同一步添加并同时编辑多个最多 10 × 10 的矩阵；可点击矩阵名称改名（如 A 改成 B 或 X），编辑元素或交换任意两个单元格。
- 按指定行列数创建默认填 0 的新矩阵或方阵单位矩阵；从当前步骤复制一张矩阵，生成可独立编辑的新矩阵。
- 在矩阵卡片中独立增删末行或末列。
- 单元格可输入整数、分数、有限小数，以及 `x`、`2x+y`、`x²`、`(x+1)(x-1)` 等多项式；同类项会合并，分数系数精确约分。除法只支持非零数字作为除数。
- 针对选定矩阵执行初等行变换、初等列变换和转置；倍加操作的系数可输入 `x`、`1/2x+1` 等多项式，倍乘操作的系数使用非零数字或分数。新步骤保留整组矩阵；应用变换后保留当前面板中的矩阵、类型和行列选择。
- 手动添加步骤、填写说明、并排查看相邻步骤。
- 删除当前步骤中的矩阵；删除可撤销，步骤历史中的其他矩阵副本不受影响。
- 撤销编辑、矩阵改名、变换、步骤新增、矩阵删除和步骤删除。
- 矩阵仅保存在当前页面内存中；刷新或关闭页面后清空，不保存到桌面或浏览器存储。

矩阵不会写入桌面文件、浏览器本地存储或服务器。

矩阵乘积等组合运算由用户自行计算并录入结果矩阵；本工具负责并排编辑与记录，不自动计算乘积。

界面字号已整体调大，方便阅读。
